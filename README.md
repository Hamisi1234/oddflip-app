# Red Card Alert

Utekelezaji mpya wa mobile/backend uko hapa:

- [`flutter_app/`](flutter_app/) — Flutter app ya Android na iOS.
- [`laravel-api/`](laravel-api/) — Laravel API yenye MySQL.
- [`FLUTTER_LARAVEL_SETUP_SW.md`](FLUTTER_LARAVEL_SETUP_SW.md) — mwongozo kamili
  wa VS Code, Android emulator/simu halisi, na phpMyAdmin.
- [`laravel-api/database/schema/red_card_alert.sql`](laravel-api/database/schema/red_card_alert.sql)
  — SQL schema ya ku-import.

Folders za awali za React/Node/Capacitor zimehifadhiwa kama legacy reference
ili historia na frontend ya Figma Make isivunjwe. Kwa mobile release mpya,
`flutter_app/` ndiyo application kuu na `laravel-api/` ndiyo backend kuu.
